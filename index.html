Técnicas informáticas para Biología

Un curso práctico de introducción a Linux, la línea de comandos y Python, pensado para estudiantes de 4º de Biología sin experiencia previa en programación.

Entrar al curso

Contenidos

11 módulos: terminal, expresiones regulares, pipelines de shell y programación en Python aplicada a datos biológicos.

Enfoque

Ejercicios prácticos paso a paso con datos reales de biología, listos para copiar y ejecutar localmente.

Requisitos

Un equipo con Linux, macOS o WSL, Python 3, y un editor de texto como gedit.
